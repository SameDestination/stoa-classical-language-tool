# Historical release packages

Packages for STOA 2 through 5.9.7 were published as assets of the
`archive-2026-10-09` release. They are no longer distributed:

- They bundle the Vusillus font, whose redistribution terms are not
  documented. STOA now uses Noto Serif STOA for Ancient Greek, and users can
  import their own fonts.
- The 5.9.7 Desktop packages include an AI provider integration that STOA no
  longer ships.

The packages are not rebuilt or repacked. Changing a published package would
alter files whose checksums are recorded below, and the 5.x Portable packages
need the bundled font file to export Greek PDFs. Current builds are published
as regular releases; see the
[latest release](https://github.com/SameDestination/stoa-classical-language-tool/releases/latest).
